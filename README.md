# LROC NAC 同条件多重撮影ファインダー

月周回機 LRO のカメラ LROC の **NAC 画像**（高解像度）のうち、**同じ場所を、似た照明条件で何度も撮った場所**を探すツールです。
結果は月面の地図の上にヒートマップで表示され、どこに多いかが一目でわかります。QuickMap に重ねるファイルも書き出せます。

たとえば「赤道付近で、太陽が横から当たる（影が長い）条件の画像を何枚も撮っている場所」を探す、といった使い方を想定しています。

## 必要なもの

- Python 3.8 以上（Windows で動作確認。画面は標準の tkinter なので、追加インストールは不要です）
- 月面の写真を地図の下に敷きたい場合だけ、Pillow が必要です
- また最初に起動した後、quickmapからデータをダウンロードする必要あるため１時間近く放置する必要あります！！！！！

```
pip install -r requirements.txt
```

Pillow が無くても動きます。そのときは、写真なしのヒートマップだけが出ます。

## 起動のしかた

```
python lroc_nac_finder.py
```

Windows では、黒い画面を出さずに起動したいときは `pythonw lroc_nac_finder.py` を使います。
デスクトップのショートカットは、リンク先を `pythonw.exe`、引数を `lroc_nac_finder.py` のフルパス、作業フォルダをこのフォルダにして作れます。アイコンは `lroc_nac_finder.ico` を使えます。

## 使い方

1. 左上の欄に条件を入れて **[検索]** を押します。
   - 緯度・経度の範囲（空欄なら月全体）
   - 入射角（太陽の高さ。大きいほど影が長い）の範囲
   - エミッション角（カメラの傾き）の範囲
   - **入射角の差・エミッション角の差**: セルの中の画像を1枚ずつ基準にして、その画像から差が何度以内の画像を「同じ条件」として集めます。撮影回数が一番多くなる組を、そのセルの結果にします。エミッション角の差は空欄なら制限なし
   - 入射角・エミッション角の最小・最大は空欄にでき、差だけで探せます（空欄なら入射角40〜80°、エミッション角0〜10°の全部）
   - グリッドの大きさ、表示する最小撮影回数
   - 太陽の向き（東＝朝、西＝夕。北が上の地図で見たとき）
   - **「赤道付近だけ」** にチェックを入れると、緯度 ±N° だけを探します
2. 結果は **順位表** と **地図** に出ます。色が濃いほど撮影回数が多い場所です。
3. 地図の操作:

   | 操作 | 動き |
   |---|---|
   | ホイールを回す | カーソル位置を中心に拡大・縮小 |
   | ホイールを押しながらドラッグ / 右ドラッグ | 地図を動かす |
   | 右クリック | 全体表示に戻る |
   | 左クリック | セルを選ぶ（撮影ID が下に出る） |
   | 選んだセルの中を左クリック | 点を打つ（1つだけ）。その点が写っている画像だけに絞り込み、その画像の範囲を撮影ごとに色分けした線で描く（初回はODEから画像の範囲を取得して保存）。別の場所をクリックするかドラッグすると点が動く。Delete か［点・四角を消す］で消す |
   | セルの中を左ドラッグ | 四角で囲む。その四角全体を写している画像だけに絞り込む（点と同じく、画像の範囲を色分けして描き、枚数を出す）。囲み始めたセルの中に収める |
   | ダブルクリック | そのセルの中心に点を置いた QuickMap をブラウザで開く |
   | 順位表の行をクリック | その場所へ拡大 |

4. 画面の右上のほうに、次の機能があります。
   - **地名を表示 / 地名へ移動**: 静かの海、アポロ着陸地点などの名前を地図に出します。
   - **月面の写真を下に敷く**、ヒートマップの **濃さ**、**配色**（色覚に配慮した配色もあります）
   - **ダークモード**
   - 検索の条件と、これらの表示の設定は保存され、次に開いたときもそのままになります。
5. 書き出し・保存:
   - **GeoJSON 書き出し / KML 書き出し**: QuickMap などに重ねるファイルです。撮影回数に応じて色が付きます。
   - **CSV 保存**: 選んだセルの画像一覧、または順位表を保存します。撮影ID（`M1274075475` のような名前。左右カメラの LE/RE は除いたもの）も入ります。

## 初回の検索について

画像のメタデータ（位置・入射角など）は NASA の公開サーバーから取得します。
取得した情報はこのフォルダの `lroc_nac_cache.sqlite` に保存され、**2回目からはネットを使わずに検索できます**。

- 取得は 30°×10° の区画ごとに行い、赤道に近い区画から順に進めます。
- 途中で中止しても、保存済みの区画は残り、次回は続きから再開します。
- 月全体を取るには時間がかかります。まず範囲を狭めて（または「赤道付近だけ」で）試すのがおすすめです。
- 保存ファイルは大きくなります（筆者の環境で約190MB）。
- 保存するのは、入射角 40〜80°、エミッション角 0〜10° の画像だけです。この範囲の外の条件では検索できません。

月面の写真のタイルは、地図を拡大したときに `tile_cache/` に保存されます。QuickMap と同じように、細かいタイルが届くまでは粗いタイルを引き伸ばして仮に表示し、画面の中心に近いタイルから順に差し替えます。表示範囲のすぐ外側のタイルも先に取っておくので、少し動かしてもすぐ表示されます。

## データの出どころ

- 画像のメタデータ: [NASA PDS Geosciences Node の ODE REST](https://oderest.rsl.wustl.edu/)（LRO / LROC の NAC。EDR を優先）
- 背景の月面写真: NASA Moon Trek の LROC WAC モザイク
- 重ね先の地図: [LROC QuickMap](https://quickmap.lroc.im-ldi.com/)

## QuickMap との連携について

- GeoJSON / KML は、QuickMap への読み込みで色が付くかを確認できていません。GeoJSON で色が付かないときは、KML をお試しください。
- ダブルクリックで開く QuickMap のURLは、共有リンクの書式から読み取ったものです。範囲指定と点の表示は、ブラウザでの確認が十分ではありません。ずれる場合は、コピーされた座標を QuickMap の座標移動欄に貼り付けてください。
- QuickMap 側で「NAC を選ぶ」「入射角で絞る」設定までは、URLでは指定できません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `lroc_nac_finder.py` | 本体。起動するファイル（画面の組み立て、条件の読み取り、検索の実行） |
| `nac_data.py` | データの取得（ODE）・集計・PC内への保存、ヒートマップの色 |
| `map_view.py` | 地図の描画と操作（拡大・移動・セルの選択） |
| `results.py` | 撮影IDの表示、画像ページを開く、CSV 保存、GeoJSON / KML 書き出し |
| `moon_basemap.py` | 月面の背景地図（WAC タイルの取得と重ね合わせ） |
| `ui_theme.py` | ライト / ダークの配色 |
| `place_names.py` | 地名データ（足したい地名はここに1行足します） |
| `lroc_nac_finder.ico` | アイコン |
| `HANDOFF.md` | 開発の引き継ぎメモ |

## 実行すると作られるファイル

次のファイルは、実行すると自動で作られ、git には含めていません: `lroc_nac_cache.sqlite`（取得データ）、`tile_cache/`（月面写真）、`lroc_nac_settings.json`（前回の検索条件と、ヒートマップの濃さ・配色・ダークモードなどの表示の設定。検索したときと閉じたときに保存し、次に開くとそのまま戻る）。
